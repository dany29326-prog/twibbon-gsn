# 🇮🇩 Twibbon Maker - Tasyakuran HUT RI ke-81

Aplikasi web sederhana untuk membuat twibbon **Tasyakuran HUT RI ke-81** bersama Garda Satya NKRI. Cukup upload foto pribadi, atur posisi & ukurannya, lalu unduh — tanpa perlu install aplikasi apapun.

## ✨ Fitur

- 📸 Upload foto pribadi langsung dari HP atau komputer
- 🔍 Perbesar/perkecil foto sesuai keinginan
- 🖐️ Geser posisi foto agar pas di dalam bingkai
- 🖼️ Bingkai twibbon sudah tertanam otomatis, tidak perlu upload ulang
- ⬇️ Unduh hasil twibbon dalam format PNG resolusi tinggi
- 📱 Responsif — bisa dipakai di HP maupun desktop
- 🌐 Berjalan 100% di browser, tidak ada data yang diunggah ke server

## 🚀 Cara Pakai

1. Buka halaman web/link twibbon
2. Klik **"Pilih Foto Anda"** dan unggah foto pribadi
3. Geser dan atur zoom foto agar pas di dalam bingkai
4. Klik **"Unduh Twibbon Sekarang"**
5. Bagikan twibbon-mu di media sosial 🎉

## 🛠️ Teknologi

- HTML5 Canvas untuk render gambar
- Vanilla JavaScript (tanpa dependency/build tool)
- Tailwind CSS (via CDN) untuk styling

## 📂 Struktur

Aplikasi ini adalah **single-file HTML** — cukup satu file `index.html` yang sudah berisi semua logika, style, dan gambar bingkai (tertanam dalam format base64), sehingga bisa langsung dijalankan tanpa proses build.

## 📄 Lisensi

Bebas digunakan untuk keperluan Tasyakuran HUT RI ke-81 Garda Satya NKRI.
